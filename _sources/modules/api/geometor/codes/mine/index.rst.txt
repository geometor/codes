geometor.codes.mine
===================

.. py:module:: geometor.codes.mine

.. autoapi-nested-parse::

   Mining layer: extract declarations from the base-context systems.

   Each miner turns one system into a list of `Decl` records. Snapshots are
   written as deterministic JSONL under ``resources/mined/`` so that ``codes``
   works without ``_refs/`` checkouts (for example on CI).

.. py:class:: Decl

   One declaration mined from a system.

   :ivar system: System key from ``context.toml`` (e.g. ``"leaneuclid"``).
   :ivar id: Identifier unique within the system (e.g. ``"Elements.Book1.proposition_5"``).
   :ivar name: Short display name.
   :ivar kind: Declaration kind (``axiom``, ``theorem``, ``rule``, ``construction``,
               ``definition``, ``postulate``, ``common_notion``, ``relation``, ``sort``,
               ``predicate``, ``measure``, ``method``, ``foundation``).
   :ivar module: Hierarchical location inside the system (path-like).
   :ivar family: Grouping used by the system itself (file, book, category).
   :ivar statement: Formal statement as written in the system.
   :ivar text: Natural-language text (docstring, description, enunciation).
   :ivar premises: Premise atoms (rule-like systems), raw syntax.
   :ivar conclusions: Conclusion atoms, raw syntax.
   :ivar uses: Other declarations cited by this one (proof trace / dependencies).
   :ivar source: Source file relative to the workspace root.
   :ivar line: 1-based line number in ``source``.
   :ivar extra: System-specific fields.
