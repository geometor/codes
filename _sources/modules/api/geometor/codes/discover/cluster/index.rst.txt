.. py:function:: discover_principles(snap_dir: pathlib.Path | None = None, lexicon: geometor.codes.lexicon.Lexicon | None = None, manifest: geometor.codes.context.ContextManifest | None = None) -> Catalog

   Run Phase 2 discovery across all mined base snapshots.

   Every base declaration is either assigned to a `Principle` cluster or
   recorded in `out_of_scope`.

   :param snap_dir: Snapshot directory (defaults to ``resources/mined``).
   :param lexicon: Optional `Lexicon`.
   :param manifest: Optional `ContextManifest`.

   :returns: A `Catalog`.
