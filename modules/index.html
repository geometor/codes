Modules¶

geometor.codes is organized into focused data-registry, exact symbolic modeling, SVG rendering, and CLI exploration modules:

  • geometor.codes — Public package interface exporting CodesRegistry, FIGURE_SPECS, build_all_figures(), render_svg(), and run_cli().

  • geometor.codes.registry — Immutable Python 3.13 dataclasses (SystemProfile, SyntaxEntry, OpusDomain, OpusTopic, RosettaBenchmark, HierarchyLayer, ArchitecturalRecommendation) and standalone offline-resilient query engine over resources/*.json.

  • geometor.codes.figures — Nine 100% exact float-free geometor.model.Model(..., auto_intersect=False) construction builders verified via zero_test, quadrance, line_spread, vertex_spread, signed_area2, and cross_ratio.

  • geometor.codes.render — Interactive dark-canvas .euclid-graphic.codes-diagram SVG renderer supporting pan/zoom, guide/label toggles, and two-way :g: \(\leftrightarrow\) data-ref hover illumination.

  • geometor.codes.cli — Rich terminal explorer (codes summary, codes decode, codes opus, codes rosetta, codes hierarchy, codes build-figures).
