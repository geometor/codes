geometor.codes.registry¶

Typed registries, cross-system query helpers, and optional _refs/ inspector.

Loads the five canonical comparative datasets from resources/ (systems.json, syntax_lexicon.json, opus_matrix.json, rosetta_benchmarks.json, and geometor_hierarchy.json) into immutable Python 3.13 dataclasses. Gracefully operates 100% standalone on CI when external _refs/ clones are absent.
