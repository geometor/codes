geometor.codes.lexicon¶

Canonical lexicon: one name per geometric concept, aliased across systems.

The lexicon lives in resources/lexicon/lexicon.toml and is seeded from the function vocabulary of geometor.etc (ops.py). See resources/lexicon/conventions.md for the naming rules.
