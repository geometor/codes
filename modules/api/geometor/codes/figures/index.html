geometor.codes.figures¶

Exact geometor.model SVG figure generators for GEOMETOR Codes.

Every model is constructed strictly with Model(…, auto_intersect=False) and 100% exact SymPy coordinates (zero sp.Float), verified symbolically via Rational Trigonometry (quadrance, line_spread, vertex_spread, cross_ratio), and rendered as an interactive .euclid-graphic SVG in docsrc/_static/figures/.
