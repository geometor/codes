geometor.codes.graphs¶

Graphviz DOT builders for the foundations views.

Every function returns a DOT source string suitable for Sphinx’s .. graphviz:: directive (rendered to SVG). Graphs are theme-neutral: transparent background, filled nodes with dark text, grey edges.

Attributes¶

BRIDGE_STYLES

Edge color and style per bridge kind.

STATUS_COLORS

Node fill per showcase realization status.
