Syntax Field Guide & Symbol Decoder¶

To a working geometer or Python engineer, opening a file in LeanEuclid, GeoCoq, mathlib4, AlphaGeometry, kingdon, or Oliver Byrne’s 1847 Coloured Euclid can feel like reading cuneiform. Symbols like -ᵥ, (2 : ℤ) • ∡, |(a─b)|, Bet, FSC, eqangle, &, >>, and :: compress entire philosophical commitments into two or three keystrokes.

This Field Guide decodes every strange symbol from first principles, pairs each syntactic family with an exact geometor.model .euclid-graphic diagram, and concludes with the complete 60-Symbol Master Decoder Reference.

1. Pointer Dereferencing vs. Byrne’s Chromatic Value-Tokens¶

The deepest syntactic divide in the history of geometry is how prose refers to a geometric locus:

  • Symbolic Pointer / Identifier Binding (Euclid, LeanEuclid, GeoCoq, mathlib4, AlphaGeometry, geometor.model): Points are bound to alphanumeric identifiers (A, B, C), and higher-dimensional objects are addressed indirectly as compound pointer expressions (Segment(A, B), |(a─b)|, ∠ p₁ p₂ p₃). This scales to arbitrary complexity and plain-text verification, but forces the human reader to perform constant visual pointer-chasing between prose text and diagram labels.

  • Pointer-Free Chromatic Value-Tokens (Byrne 1847 / Rougeux 2018): Oliver Byrne eliminated vertex letters across Books I–VI (Byrne1847), embedding miniature colored segments [━━], angle wedges [◣], squares [□], and circles [○] directly as r-values inside vertical Given / To Prove / Construction / Proof equations (with Oughtred’s :: proportion and Rahn’s ∴ discharge). Similarly, 2D Projective Geometric Algebra (PGA) manipulates whole line blades l1 ^ l2 without referencing vertex coordinates.

  • GEOMETOR’s Bidirectional Synthesis (:g: \(\leftrightarrow\) data-ref): Following Nicholas Rougeux’s interactive web edition (Rougeux2018), GEOMETOR’s :g: role (e.g., AB, AB, F) retains exact symbolic identifiers while illuminating the matching SVG locus on hover—uniting unlimited symbolic arity with zero-dereference visual perception.

2. Dependent Type Binders & Logical Quantifiers (Lean 4 & Coq)¶

Interactive theorem provers (LeanEuclid, mathlib4, GeoCoq) use the Curry–Howard correspondence: a theorem is a type, and a proof is a functional program constructing an inhabitant of that type.

  • Explicit vs. Implicit vs. Typeclass Binders: - (a b : Point) — Explicit arguments you pass by hand when applying a lemma. - {V P : Type*} — Implicit arguments inferred automatically by unification from later arguments. - [NormedAddTorsor V P] (Lean 4) or Context `{TnEQD : Tarski_neutral_dimensionless_with_decidable_point_equality} (Coq) — Typeclass instances synthesized automatically in the background to endow P with geometric structure.

  • Quantifiers & Connectives: ∀ / forall introduces arbitrary givens; ∃ / exists demands an explicit constructive witness (unless bypassed via Classical.choose); → / -> chains hypotheses to conclusions; ∧ / /\ bundles conjunctions; ¬ / ~ negates degeneracies such as ¬ Col A B C.

3. Diagrammatic System E & Topological Root Selectors¶

When a line meets a circle or two circles meet, algebra yields a degree-2 quadratic equation with two roots. How does a formal language pick the right one without floating-point coordinates?

In LeanEuclid (AvigadDeanMumma2009, Murphy2024), SystemE/Theory/Constructions/Intersections.lean provides seven constructive rules (intersect_circles_same_side, intersect_circles_opposing_sides, intersect_line_circle_between, intersect_line_circle_extending), while linear metric terms are written |(a─b)| (length), ∠(a:b:c) (angle), ∟ (right angle), and △(a:b:c) (area). geometor.model.intersect implements the exact algebraic counterparts via signed_area2 and dot-product ordering—without LeanEuclid’s unverified SMT_VERIF axiom!

4. Tarski’s Point-Only Predicates (GeoCoq)¶

In Alfred Tarski’s minimalist language (Schwabhauser1983, Boutry2019), lines, circles, and angles do not exist as types. Every geometric statement is built from points (Tpoint) and two predicates:

  • Bet A B C — Non-strict collinear betweenness (Bet A A B is always true!). Collinearity Col A B C is simply Bet A B C \/ Bet B C A \/ Bet C A B.

  • Cong A B C D — Segment AB is congruent to CD.

  • Per A B C — Right angle ∠ABC defined without angles: there exists C' such that B is the midpoint of C and C' and Cong A C A C'!

  • FSC — Tarski’s angle-free Five-Segment Configuration replacing Euclid’s SAS (I.4).

5. Affine Torsors, Directed Angles & Rational Spreads¶

mathlib4 separates points P from vectors V via NormedAddTorsor V P: subtracting two points p₁ -ᵥ p₂ yields a vector in V, while v +ᵥ p translates a point by a vector (note p₁ + p₂ is a type error!). For angles, mathlib4 distinguishes unoriented ∠ p₁ p₂ p₃ ∈ [0, π] from oriented ∡ x y z ∈ ℝ / 2πℤ, using twice-angles (2 : ℤ) • ∡ x y z to represent directed line angles modulo π—the exact same group used by eqangle in AlphaGeometry/JGEX! In geometor.model and geometor.wildberger, both transcendental angles and square-root norms are replaced by rational quadrance \(Q\) and spread \(s = \sin^2\theta\).

6. Olympiad Clause Stanzas & Coordinate-Free Area Elimination¶

AlphaGeometry and Newclid read compact 1-line problem clauses (premises ? goal) backed by 5-line macro stanzas in defs.txt (signature, dependency, non-degeneracy, postconditions, compass realization). Watch out for two forensic traps we uncovered in alphageometry: post-semicolon clauses without a x : prefix in defs.txt are silently dropped by Graph.add_clause, and RatioTable.add_const_ratio in ar.py:425-431 encodes \(m \log|s_1| = n \log|s_2|\) instead of \(|s_1|/|s_2| = m/n\)!

Meanwhile, JGEX’s coordinate-free Area Method eliminates constructed points backward from signed parallel ratios \(r\), signed areas \(S_{ABC}\), and Pythagoras difference \(P_{ABC} = AB^2 + BC^2 - AC^2\) using the Co-Side Theorem: \(PM / QM = S_{PAB} / S_{QAB}\).

7. Clifford Blades (PGA/CGA) & Homogeneous CP^2 Matrices¶

In kingdon’s 2D Projective Geometric Algebra (Algebra(2, 0, 1)), lines are grade-1 vectors, points are grade-2 bivectors, ^ is meet, and & is join. In 2D Conformal Geometric Algebra (Algebra(3, 1)), points lift onto the 4D null cone \(P = x e_1 + y e_2 + \tfrac{1}{2}(x^2+y^2)n_\infty + n_o\), so P1 ^ P2 ^ P3 is the circle through three points, -2*(kappa | P) is Steiner power, kappa1 - kappa2 is the radical axis, and C >> P is circle inversion! (Critical warning: in ``galgebra``, ``>>`` is the commutator product, ``&`` is missing, and ``.dual()`` crashes when :math:`I^2 = 0`!) In CindyJS’s \(\mathbb{CP}^2\), cross(u, v) computes both join and meet, C * p is the polar line, and adjoint3(C) * l is the pole.

FSC

geocoq

Five-Segment Configuration — Tarski’s angle-free replacement for SAS triangle congruence: if collinear triples (A,B,C) and (A’,B’,C’) have matching base segments and matching legs to apexes D, D’, then the 5th segments CD and C’D’ are congruent.

FSC A B C D A’ B’ C’ D’ := Col A B C /\ Cong A B A’ B’ /\ Cong B C B’ C’ /\ Cong A D A’ D’ /\ Cong B D B’ D’. Example: Lemma l4_16 : FSC A B C D A' B' C' D' -> A <> B -> Cong C D C' D'.

Per

geocoq

Tarski right angle via midpoint reflection — Angle ABC is a right angle iff reflecting C across B to C’ makes A equidistant from C and C’—defining 90 degrees with zero angle primitives!

OS

geocoq
