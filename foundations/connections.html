Shared ontology¶

Each system linked to its primitive sorts. Hubs (Point, Line, Circle) are near-universal; the periphery shows what is distinctive — Tarski’s betweenness and congruence, mathlib’s vectors and spheres, multivectors, homogeneous coordinates.

Shared principles¶

Edges join base systems that realize the same discovered principle; edge labels and widths count the shared principles. This replaces the long coverage matrix — drill into the catalog with the system filters for the rows.
