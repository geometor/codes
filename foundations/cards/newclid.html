Newclid¶

L3 Rule-closed · Archetype: rule-engine · upstream · dossier

Believe it because the DDARN engine derived it from a curated rule set descended from AlphaGeometry — again with numerically checked side conditions.

Trust chain¶

Ontology

AG predicates plus metric ones (pythagoras, obtuse_angle, sameclock). (What exists?)

Language

JGEX/AG-style construction text wrapped in Python (JGEXFormulation.from_text). (How is a statement written?)

Assumptions

87 Rule objects; DEFAULT_RULES = ALL − DEACTIVATED − TRIAGE (~58). (What is taken as given?)

Engine

DDARN: rule matching + sympy.solve AR tables; optional Yuclid C++ solver. (How are new truths derived?)

Certificate

Justification graph and written proof. (What evidence is left behind?)

Checker

Python + SymPy + rule soundness + numeric checks (rel tol 1e-3). (What must be trusted?)

Semantics

As AlphaGeometry: one float diagram of the real plane. (What model makes it sound?)

At a glance¶

Logic / calculus:

Horn-clause forward chaining

Exact vs numeric:

Exact algebra; numeric side conditions

Decision procedure:

Saturation over a finite rule set

Role of the diagram:

Essential: every predicate checked numerically first

Degeneracy handling:

Numeric filters

Trusted base (size):

~15.4k lines Python (+15k C++)

Trusts:

Newclid DDARN (~15.4k lines Python (+~15k C++ Yuclid)) · SymPy simplification (core heuristics + mpmath) · Numeric diagram (tol 1e-12 (AG) · rel 1e-3 (Newclid))

Catalog:

86 principles (39 shared with other systems) — search

Findings¶

  • 87 live rules (r00–r42 from AlphaGeometry); about 58 active by default after DEACTIVATED and TRIAGE sets.

  • R57 Pythagoras is deactivated; R45 Simson is left out as provable from other rules.

  • Numeric tolerance REL_TOL = 0.001 (numerical/__init__.py) — far looser than AG’s 1e-12.
